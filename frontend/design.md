# TerraPulse Design System

## Vision

TerraPulse should feel like a premium environmental intelligence platform.

Not a government dashboard.
Not an admin panel.

The visual direction combines:

- Apple-style spacing
- Arc Browser softness
- Modern climate-tech branding
- GIS intelligence platform aesthetics

The goal is to communicate:

- Trust
- Sustainability
- Precision
- Intelligence

---

# Design Inspiration

Primary Inspiration:

- Apple
- Arc Browser
- Linear
- Stripe Dashboard
- Green Roots Design Reference

Reference Characteristics:

- Large rounded corners
- Soft shadows
- Spacious layouts
- High readability
- Premium typography
- Card-first interfaces

---

# Design Language

Keywords:

- Organic
- Premium
- Calm
- Data-driven
- Sustainable
- Modern
- Geographic

---

# Border Radius

Use generous rounding everywhere.

Cards:
24px

Buttons:
999px

Inputs:
18px

Map Containers:
32px

Modals:
32px

Charts:
24px

---

# Shadows

Avoid harsh shadows.

Example:

shadow-[0_8px_30px_rgb(0,0,0,0.08)]

---

# Glass Effects

Only for:

- Navigation
- Floating Actions
- Filters

Use subtle blur.

Never overuse glassmorphism.

---

# Layout Philosophy

Everything lives inside cards.

No hard edges.

Every section should feel like a physical panel floating above the background.

---

# Page Structure

Navbar

↓

Overview Cards

↓

Map Section

↓

Analytics Section

↓

Activity Feed

---

# White Space

Large spacing.

Never cram information.

Padding:

- Small: 16px
- Medium: 24px
- Large: 32px
- Section: 64px

---

# Motion

Use Framer Motion.

Animations:

- Fade In
- Slide Up
- Hover Lift
- Map Fly Animation

Duration:

200ms - 400ms

No flashy animations.

---

# Product Personality

TerraPulse feels like:

"Apple designed a climate intelligence platform."
